## 🎮 Contrôles

| Touche          | Action      |
| --------------- | ----------- |
| **ZQSD**        | Se déplacer |
| **Clic gauche** | Utilise l'object sélectionner  |
| **Clic droit** | Tirer un cable (premier clic au premier point, deuxième au point d'arriver)|
| **Scroll**      | Change l'object sélectionner   |
| **E**           |    Interagir avec les ùachine |
